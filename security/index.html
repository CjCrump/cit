Security

How this site handles your information, and how to report a problem.

What I keep

This site has no accounts and no database.

  • The contact form sends your name, phone or email, the service you picked and your message to my inbox through Web3Forms. Nothing is saved on this site.
  • I don't set cookies or run ad trackers or analytics. Fonts load from Google Fonts.
  • The shop at shop.chanceitstudio.com has its own security page.

How the site is protected

  • HTTPS only, hosted on Cloudflare.
  • A strict Content Security Policy, so pages only run this site's own code.
  • Security headers that stop other sites from framing these pages.
  • Spam checks on the contact form.

Report a problem

Found a security issue? Email chance@chanceitstudio.com with what you found and how to see it. Please give me a chance to fix it before you share it publicly.
